# 02 資料結構說明

所有內建資料都放在 `index.html` 的 `<script type="application/json" id="data-*">` 區塊，共 7 個資料集。每個區塊都是一份完整的 JSON，可以用任何文字編輯器修改。

| 資料集 | 區塊 id | 內容 |
|---|---|---|
| trip | `data-trip` | 旅行期間、預設人數、匯率、Tabin／Danum 夜數、節日 |
| itinerary | `data-itinerary` | 9 天行程、住宿、活動、可選安排、雨天備案 |
| costs | `data-costs` | 費用項目與計價規則，加上 BRL／DVFC 方案比較（`compare`） |
| species | `data-species` | 目標哺乳類（人工維護的生態資料加 iNaturalist 快照） |
| locations | `data-locations` | iNaturalist 查詢範圍、地圖 POI、行程示意路線 |
| sources | `data-sources` | 所有資料來源、查核日期、可信程度 |
| essentials | `data-essentials` | 風險表、出發前清單、生態倫理、夜間注意事項 |

## 共通規則

- **未知值寫 `null`，不要寫 `0`。** 價格寫 `0` 表示免費，寫 `null` 表示「未報價」。
- 資料狀態 `status`：

| 值 | 介面顯示 | 何時使用 |
|---|---|---|
| `quoted` | 業者報價 | 業者書面報價（例如 Tabin 信件） |
| `public_rate` | 公開牌價 | 官網公開價格，不等於你們實際拿到的價格 |
| `confirmed` | 已確認 | 有可靠來源，或已取得業者書面確認 |
| `estimate` | 估算 | 依假設推算，`assumption` 必須寫出假設 |
| `demo` | 示範資料 | 只為了讓功能能運作，不是報價 |
| `unquoted` | 未報價 | `price` 必須是 `null` |

- 每項資料都用 `source_ids` 連到 `sources`。來源要寫查核日期 `checked_on`。

## costs：費用項目

```json
{
  "id": "night_safari",
  "name": "Private Night Safari（Tabin）",
  "category": "per_person",
  "unit": "per_person_per_night",
  "qty": { "nights_from": "nightSafariNights" },
  "quoted_nights": 3,
  "price": 130,
  "price_currency": "MYR",
  "status": "quoted",
  "applies": "always",
  "includes": ["私人夜間觀察"],
  "excludes": [],
  "duplicate_risk": ["tabin_base"],
  "assumption": "…",
  "source_ids": ["src_quote_a"]
}
```

| 欄位 | 說明 |
|---|---|
| `category` | 決定項目顯示在哪一區：`group_fixed` 團體固定成本、`per_person` 按人計價、`danum` Danum 住宿套裝、`other` 其他 |
| `unit` | 計價單位，見下表 |
| `qty` | 數量參數：`days`、`nights`、`trips`；`nights_from`／`rooms_from` 表示從計算情境取值 |
| `price` | 數字（報價或牌價），或 `{low, mid, high}`（估算或示範，依情境切換），或 `null`（未報價） |
| `price_currency` | `MYR`（預設）或 `TWD`。TWD 項目會用匯率換回 MYR 再加總 |
| `applies` | 何時計入：`always`、`brl`、`dvfc`、`flights`（機票開關）、`extras`（其他費用開關）、`optional`（可選，`default_on` 決定預設） |
| `when` | 額外條件：`singles` 表示有單人入住時才計入 |
| `duplicate_risk` | 內容可能重疊的項目 id。兩項同時計入時會顯示警告，但不會自動扣除 |
| `quoted_nights` | 報價的晚數。行程選擇的晚數和它不同時會提醒 |

**計價單位（`unit`）**

| unit | 數量計算 | 固定／變動 |
|---|---|---|
| `per_person` | 人數（整個套裝一次） | 變動 |
| `per_group` | 1 | 固定 |
| `per_group_per_day` | `qty.days` | 固定 |
| `per_person_per_night` | 人數 × 晚數 | 變動 |
| `per_room_per_night` | 房數 × 晚數 | 變動 |
| `per_person_trip` | 人數 × `qty.trips` | 變動 |
| `per_person_day` | 人數 × `qty.days` | 變動 |

**計算流程**：純函式 `EcoCore.computeBudget(data, state)`，和畫面完全分開。

1. 依 `applies` 和 `when` 判斷這項是否計入。
2. 依 `unit` 和 `qty` 算出數量。
3. 決定單價。使用者自訂單價優先，其次是報價或牌價，再其次是情境價；未報價為 `null`。
4. 金額 = 單價 × 數量；如果是 TWD 計價，再換算成 MYR。
5. 小計只加總有金額的項目。未報價的項目列入「尚未估價」，同時拉低完整度。
6. 預備金 = 小計 × 比例。每人平均 = 總計 ÷ 人數。

**私人夜遊晚數的連動**：行程中夜間活動的 `options[i].cost_ref = "night_safari"` 被選了幾晚，費用就算幾晚。

**`compare`（方案比較）**：

- `criteria`：評分準則。其中 `budget` 一項會依試算結果自動計分。
- `options.brl` 和 `options.dvfc`：各自的 `scores{key:{s, why}}`（1–5 分，加上評分理由）、`pros`、`cons`。
- `rows`：比較表，每一列是 `{label, brl:{text,status,source_ids}, dvfc:{…}}`。
- `questions`：要向業者確認的問題，中英對照。

## itinerary：行程

```json
{
  "day": 6, "date": "2027-02-03", "region": "transit", "short": "Tabin → Danum",
  "kind": ["transfer"], "segment_days": ["tabin", "danum"],
  "lodging_prev": "tabin_resort", "lodging": "danum_choice", "lodging_status": "public_rate",
  "activities": [{
    "id": "d6-t2", "slot": "afternoon", "type": "transfer", "title": "…",
    "start": null, "duration_h": null, "effort": 1, "status": "tbc",
    "location": "danum_choice", "needs": ["booking"], "species": [],
    "options": [{ "label": "…", "cost_ref": "night_safari" }], "default_choice": 0,
    "plan_notes": { "brl": "…", "dvfc": "…" }, "detail": "…"
  }],
  "notes": ["…"], "weather_alt": "…"
}
```

**特殊住宿代碼**

| 代碼 | 解析為 |
|---|---|
| `danum_choice` | 目前選的 BRL（`brl`）或 DVFC（`dvfc`） |
| `last_night_choice` | `ld_hotel`、`kk_hotel`，或「未決定」（`null`，會顯示待確認） |

**其他欄位**

- `slot`：`dawn`、`morning`、`afternoon`、`evening`、`night`。
- `type`：`transfer`、`walk`、`night`、`rest`、`meal`、`landscape`、`flight`。
- `effort`：體力需求 1–3。
- `status`：`confirmed`、`suggested`、`tbc`。
- 交通時間未查證時，`duration_h` 填 `null`，畫面會顯示「時間未查證」。

**品質檢查**（`EcoCore.checkItinerary`）：

- 天數和日期連續性。
- 每晚都有住宿，Tabin 和 Danum 的夜數正確。
- 今晚住宿等於明天的前一晚住宿。
- 有 `start` 和 `duration_h` 的活動不可重疊。
- 交通日不安排高強度活動。
- 待確認項目、春節。
- 和報價交叉比對：夜遊晚數、嚮導天數。

## species：物種

```json
{
  "id": "orangutan", "flagship": true,
  "zh": "婆羅洲猩猩", "zh_source": "src_xxx",
  "en": "Bornean Orangutan", "sci": "Pongo pygmaeus",
  "order": "Primates", "family": "Hominidae", "inat_taxon_id": 43578,
  "iucn": { "status": "CR", "source_id": "src_iucn_inat", "checked_on": "2026-11-10" },
  "records": {
    "tabin": { "lit": "recorded", "lit_source": "src_xxx",
               "inat_snapshot": { "total": 12, "latest": "2025-08-01", "checked_on": "2026-11-10" } },
    "danum": { … }
  },
  "activity": "diurnal", "habitat": "…", "method": "…", "difficulty": 2, "sensitive": false,
  "summary": "…", "source_ids": ["…"], "checked_on": "2026-11-10"
}
```

- `inat_snapshot` 是研究當天人工記錄的 API 結果，畫面上標為「快照」。點開物種後會另外查詢即時資料，即時結果只存在記憶體和快取中，**不會寫回物種資料**。
- `lit` 的值：`recorded`（文獻或業者資料有紀錄）、`not_found`（查核的來源中沒有）、`unknown`（未查證）。
- 觀察可能性標籤由 `EcoCore.observabilityLabel` 依公開規則產生，規則見 `docs/01`。

## locations：地點

```json
{
  "areas": [{ "key": "tabin", "name": "…", "inat_place_id": 12345, "place_usable": true,
              "bbox": { "swlat": 0, "swlng": 0, "nelat": 0, "nelng": 0 }, "bbox_is_approximate": true }],
  "pois": [{ "id": "brl", "name": "…", "type": "lodging", "region": "danum", "lat": 0, "lng": 0,
             "approximate": true, "summary": "…", "stay": "…", "species": [], "activities": [],
             "safety": "…", "guide": "…", "source_ids": [] }],
  "route": ["ldu", "ld_hotel", "tabin_resort", "ld_hotel", "danum_choice", "last_night_choice"]
}
```

- `type`：`lodging`、`wildlife`、`transport`、`landscape`。
- `region`：`tabin`、`danum`、`transit`，用於計算夜數。
- iNaturalist 查詢範圍的優先順序：`place_usable: true` 時用 `inat_place_id`，否則用 `bbox`。

## GAS 遠端資料格式

```json
{
  "schema": "ecotrip2027/1",
  "updated_at": "2026-12-01T10:00:00Z",
  "data": { "costs": { … }, "itinerary": { … } }
}
```

- `data` 裡可以只放部分資料集。網站會逐一驗證，通過的覆蓋內建版本，失敗的保留內建版本並顯示錯誤。
- 範例程式在 `gas/Code.gs`。

## 使用者狀態（LocalStorage `ecotrip2027.v1`）

存放人數、房數、匯率、Danum 方案、情境、預備金、費用開關、自訂單價、活動選擇／狀態／備註、當日備註、目標物種、清單勾選、評分權重、GAS 網址。

- 匯出的 JSON（`schema: "ecotrip2027-export/1"`）包含這份狀態、當下的計算結果、套用選擇後的行程和檢查結果。
- 匯入時會逐欄做型別檢查。
- iNaturalist 快取另外存在 `ecotrip2027.inat.v1`，有效期 24 小時。
