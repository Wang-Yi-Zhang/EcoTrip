## 3. 資料模型

所有資料集都內嵌在 `index.html` 的 `<script type="application/json" id="data-*">` 中，邏輯上分成 6 個 JSON 資料集。GAS 端可以整份覆蓋其中任一個。

### 3.1 共通欄位

- `status`：`confirmed`（已確認，有可靠來源）｜`quoted`（業者報價）｜`public_rate`（公開牌價）｜`estimate`（估算，須附 `assumption`）｜`tbc`（待確認）｜`demo`（示範資料）｜`unquoted`（未報價，金額必為 `null`）
- `source_ids`：對應 `sources[].id`
- 未知值一律寫 `null`，**絕不寫 0**。

### 3.2 trip

```json
{ "id":"sabah2027", "title":"…", "start":"2027-01-29", "end":"2027-02-06",
  "nights":8, "default_pax":4, "default_fx":7.2,
  "segments":[{"key":"tabin","nights":4,"check_in":"2027-01-30"},
              {"key":"danum","nights":2,"check_in":"2027-02-03"}],
  "holidays":[{"date":"2027-02-05","name":"除夕"}] }
```

### 3.3 itinerary

```json
{ "days":[{ "day":1, "date":"2027-01-29", "region":"transit|tabin|danum",
   "kind":["arrival"|"transfer"|"activity"|"departure"],
   "lodging_prev":"<location id|null>", "lodging":"<location id|'danum_choice'|null>",
   "lodging_status":"quoted|tbc|…",
   "activities":[{ "id":"d2-pm", "slot":"morning|afternoon|evening|night",
       "type":"transfer|walk|night|rest|meal|boat|other",
       "title":"…", "start":"14:00|null", "duration_h":2|null, "effort":1-3,
       "status":"confirmed|suggested|tbc", "location":"<location id>",
       "species":["<species id>"], "needs":["booking","guide","fee","permit","extra_cost"],
       "cost_ref":"<cost item id|null>", "options":["…"], "detail":"…" }],
   "notes":["…"], "weather_alt":"…" }] }
```

### 3.4 costs

```json
{ "currency":"MYR",
  "items":[{ "id":"tabin_base", "name":"…", "category":"group_fixed|per_person|danum|other",
    "unit":"per_person|per_group|per_group_per_day|per_person_per_night|per_room_per_night|per_person_trip",
    "qty":{"days":4}|{"nights_key":"night_safari_nights"}|{},
    "price":5100 | {"low":…,"mid":…,"high":…} | null,
    "price_currency":"MYR|TWD",
    "status":"quoted|public_rate|estimate|demo|unquoted",
    "applies":"always|brl|dvfc|other_toggle|optional",
    "includes":["…"], "excludes":["…"], "duplicate_risk":["<item id>"],
    "assumption":"…", "source_ids":["src_quote_a"] }] }
```

計算由純函式 `computeBudget(data, settings)` 完成，與 UI 完全分離：

- `qty = unitMultiplier(unit, ctx) × qty.days|nights`。其中 `ctx = {pax, rooms, singles, nights…}`；`per_person`→pax，`per_group`→1，`per_room_per_night`→rooms×nights。
- `price=null` 或 `status=unquoted` 的項目：金額為 `null`，不計入合計，另外列入「未估價項目」，完整度跟著下降。
- 情境（低／中／高）：報價和公開牌價三種情境都用同一個值；估算和示範項目才有 low/mid/high。
- 預備金 = 已計金額小計 × 預備金比例。
- 完整度：已計入項目中，按金額計算「報價與牌價」、「估算與示範」各占多少，另外列出未估價的項目數。
- 防止重複計費：`duplicate_risk` 互相引用的項目同時啟用時，顯示警告，但不自動刪除。

### 3.5 species

```json
{ "id":"orangutan", "zh":"…|null", "zh_source":"…", "en":"…", "sci":"…",
  "order":"…", "family":"…", "inat_taxon_id":43578|null,
  "iucn":{"status":"EN","source_id":"…","checked_on":"2026-11-10"},
  "records":{"tabin":{"lit":"recorded|not_found|unknown","source_id":…,
                      "inat_snapshot":{"total":…,"latest":"…","checked_on":"…"}},
             "danum":{…}},
  "activity":"diurnal|nocturnal|cathemeral|crepuscular",
  "habitat":"…", "method":"…", "difficulty":1-3, "sensitive":true|false,
  "summary":"…", "source_ids":["…"], "checked_on":"…" }
```

觀察可能性標籤由 `observabilityLabel(record, difficulty, live, obscured)` 依公開規則產生，並同時顯示判斷依據。

**兩種 iNaturalist 筆數**（研究 2026-11-10 實測）：

- **A（保護區 Place 筆數）**：只計座標公開的紀錄。iNat 對受威脅物種（如紅毛猩猩、象、鬚豬）遮蔽座標，這些紀錄不會出現在 Place 篩選中。
- **B（近似範圍筆數）**：用 Place 的外接矩形查詢，含座標遮蔽的紀錄，但遮蔽座標是隨機偏移的點，也包含周邊區域。

**有效證據**：A ≥ 1，或「遮蔽物種且 B ≥ 1」，或可靠文獻有紀錄。只有 Wikipedia 或 KBA 2002 年資料的文獻，算作弱證據。

| 標籤 | 條件（依各區域判斷） |
|---|---|
| 有較充分歷史觀察依據 | A ≥ 20 且難度 ≤ 2（只看保護區內的公開紀錄；B 再多也不行） |
| 有歷史紀錄，但不易觀察 | 難度 ≤ 2 且有有效證據；或難度 3 但 A ≥ 20 |
| 罕見或高度仰賴運氣 | 難度 3 且有有效證據 |
| 資料不足，無法判斷 | 沒有有效證據（只有周邊近似範圍紀錄或弱文獻時也歸在這裡） |

- 門檻 20 和難度都是本工具自訂的輔助判斷，不是統計推論，介面上會揭露。
- 紀錄多寡不等於容易看到，也不能換算成觀察成功率。

## 4. 資料載入與關聯

```
loadData():
  local = 解析內嵌的 data-* JSON（必定成功，否則顯示致命錯誤）
  若 settings.dataSource === 'remote' 且 URL 合法：
      fetch(GAS) → validateEnvelope → 每個資料集逐一 validate
      驗證通過的資料集覆蓋本機版，並標記 origin=remote；失敗的保留本機版，並記錄錯誤
  回傳 {data, origin:{costs:'local'|'remote',…}, errors}
```

- itinerary 的 `location`／`lodging` → locations.pois.id
- itinerary 的 `species` → species.id
- itinerary 的 `cost_ref` → costs.items.id（用於品質檢查：夜遊排了幾晚、報價算幾晚）
- 所有 `source_ids` → sources.id
- 啟動時執行 `validateReferences()`，參照不到的 id 會列入品質檢查。
