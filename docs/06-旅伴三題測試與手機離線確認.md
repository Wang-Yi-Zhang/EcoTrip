# 06 旅伴三題測試與手機離線確認

這兩件事只有人能做，而且結果比任何自動化測試都有說服力。請在網站部署到 GitHub Pages 之後進行。

## A. 旅伴三題測試

**目的**：確認一位沒參與規劃的旅伴，只靠網站就能找到答案。

**做法**

1. 找一位沒看過這個網站的旅伴，只給網址，不要解說。
2. 請對方邊操作邊把想法講出來。你只記錄，不提示。
3. 每題計時，超過 3 分鐘就算沒通過，並記下卡在哪裡。

## B. 手機離線確認

**目的**：確認在保護區沒有網路時網站打得開。我在電腦上的瀏覽器測過（載入後關掉伺服器再重新整理，網頁與試算正常），但實體手機沒有測過。

**步驟**

1. 在有網路的地方，用手機瀏覽器打開網站的網址，等它完全載入。
2. 依序點過每一個分頁各一次，「探索地圖」分頁停留幾秒。
3. 關閉瀏覽器分頁。
4. 打開飛航模式，關掉 Wi-Fi。
5. 重新打開瀏覽器，輸入同一個網址。

**應該看到的結果**

| 項目 | 離線時應該 |
|---|---|
| 總覽、每日行程、費用試算、旅遊準備 | 正常顯示，數字和上線時相同 |
| 待辦勾選、備註 | 可以勾選與輸入，重新打開後還在 |
| 探索地圖 | 地點清單與標記正常；底圖顯示空白或部分圖磚（圖磚需要網路） |
| 物種的 iNaturalist 即時紀錄 | 顯示「查詢失敗」或 24 小時內的快取；內建物種介紹正常 |

**如果打不開**：請記下手機型號、瀏覽器、看到的畫面。iPhone 的 Safari 會在一段時間沒開啟後清掉離線資料，所以出發前一天請再做一次第 1–2 步。

**保險做法**：出發前在電腦上按「每日行程 → 列印這一天的流程」，把 10 天各印一張，電話與訂位代號手寫在紙上。
